# okibee-tfc
want a pure terrafirmacraft experience with all of (or almost) the client-sided mods u could ever need? then Okibee TFC is made for you!
### what is a terrafirmacraft
i quote:

> TerraFirmaCraft (TFC) is a total conversion mod that overhauls and reinvents survival mode. The goal of the mod is to create a believable, challenging survival experience, in a brand new immersive setting. It completely overhauls Minecraft world generation - from adding continents, to flowing rivers, to mountain ranges, to varied and diverse forests, flora, and fauna.

oki so basically it is realistic minecraft 🐝👍

### where do i find the list of mods

you go in [[Versions]](https://modrinth.com/modpack/okibee-tfc/versions) and click the version you wanna check, mods will be listed under the "Dependencies" tab

### what if i dont have a modpack manager to open .mrpack files

you can go in [[Releases]](https://github.com/okibee/okibee-tfc/releases) and scroll down to files to install a .zip with all the mods predownloaded (but you would have to update the modpack manually afterwards)

### where do i report issues

if there are incompability problems between the mods or something related report in [[Issues]](https://github.com/okibee/okibee-tfc/issues)

if a problem happen with a mod in particular, go on the mod page and report issues here. if the issue is severe enough (unability to launch, frequent crashes, security issues, etc.) report it in [[Issues]](https://github.com/okibee/okibee-tfc/issues) too so we can temporarily remove the mod or find an alternative

### what if i have another question

go check the [[FAQ]](https://github.com/okibee/okibee-tfc/wiki/FAQ) if your question has already been answered. else you are free to ask questions in [[Issues]](https://github.com/okibee/okibee-tfc/issues) (which might get added in the [[FAQ]](https://github.com/okibee/okibee-tfc/wiki/FAQ) afterwards)

### how do i make a suggestion?

you know the drill, [[Issues]](https://github.com/okibee/okibee-tfc/issues)
